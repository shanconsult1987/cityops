
# Security Policy

## Reporting a vulnerability
Do not report security vulnerabilities in public issues.

Use the repository's private vulnerability reporting feature if enabled.
If it is unavailable, contact the maintainers through an approved private channel.

## Scope
This is a workshop demonstration. It does not connect to real municipal
systems and must not be used for real dispatch.

## Secrets
Never commit API keys, tokens, passwords or production credentials.
Rotate any credential that has been exposed.
